Detailed Description

Gestione delle configurazioni di sistema persistenti.

  • Questo modulo definisce la struttura SystemConfig che contiene i parametri operativi del dispositivo e fornisce le interfacce per inizializzare e salvare tali configurazioni nella memoria flash.
