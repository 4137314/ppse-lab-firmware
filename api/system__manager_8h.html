Detailed Description

Gestione del middleware di sistema e comunicazione IPC tra core.

Coordina lo scambio dei pacchetti di telemetria, la gestione dei report di errore e lo stato di sincronizzazione tra il Core principale e il Core di elaborazione/IO.
