bool telemetry_get_frame ( SystemDataPacket *  dest)

Copia il frame di telemetria corrente nella destinazione fornita.

Utilizza un meccanismo di accesso sicuro per evitare la lettura di dati parzialmente aggiornati (data tearing) su architetture multi-core.

Parameters
destPuntatore alla struttura SystemDataPacket di destinazione.
Returns
true se il frame è stato copiato correttamente.
