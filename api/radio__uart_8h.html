Detailed Description

Driver agnostico per la gestione delle interfacce seriali (UART0 e UART1).

Astrae le comunicazioni con il modulo GPS (SAM-M8Q) e WiFi (ESP-01). Fornisce un'interfaccia a basso livello per il buffering dei dati. Repository: https://github.com/4137314/ppse-lab-firmware
