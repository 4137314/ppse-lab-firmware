\section{Documentazione del Codice Sorgente}
\label{appendix:firmware}

In questa appendice viene riportata l'organizzazione modulare del firmware sviluppato per il SoC RP2040. La struttura del repository segue una scomposizione funzionale volta a separare l'astrazione dell'hardware (\textit{Drivers}) dalla logica di controllo (\textit{Core}) e dalla presentazione (\textit{UI}).
